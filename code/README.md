# code/

**这里只放我自己手写的代码。** 复制来的、AI 生成的，不放这里。

| 目录 | 内容 |
|---|---|
| `c/` | C 语言练习。文件名对应 `exercises/` 里的题号，例如 `A03.c` |
| `cpp/` | C++ 练习（大三下开始） |
| `ds/` | 数据结构手写实现 —— **全部自己写，不许调用现成库** |
| `linux/` | shell 脚本、系统编程练习 |
| `go/` | Go 练习（大三下开始） |

## 约定

- **编译一律用**：`gcc -Wall -Wextra -Werror`。警告等于错误。
- C 语言数据结构**不许用 STL/第三方库**——目的就是自己实现一遍。
- 每个文件头部写三行注释：

```c
// 题目：A03 · printf 格式化
// 状态：通过 / 卡在XXX
// 卡点：（一句话，说不出来就写"无"）
```

- 调试记录写进 [`journal/`](../journal/)，格式见当月日志。
