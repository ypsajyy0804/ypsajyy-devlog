Error OutOfMemoryError（内存溢出错误 - OOM），一直创建对象、不回收，最终导致 head 被占满：

import java.util.ArrayList;
import java.util.List;

public class OOMDemo {
    public static void main(String[] args) {
        try {
            List<byte[]> list = new ArrayList<>();
            int count = 0;
            
            while (true) {
                // 每次循环创建一个 1MB 的字节数组，并加入到列表中
                list.add(new byte[1024 * 1024]); 
                count++;
                System.out.println("已成功申请内存次数: " + count);
            }
            
        } catch (Throwable t) {
            System.out.println("捕获到了内存溢出: " + t);
        }
    }
}

Error 不应该被回收，不像 Exception 那种程序还能继续活下去的意外，Error 会直接导致整个程序或底层环境已经彻底崩溃或无法挽回，程序已经是不可恢复的瘫痪状态；即便利用父类  Throwable catch/捕获后，也无法实现程序后续的正常运行；

编译失败，原因是连续的 catch 不能以这种父类在前子类在后从大到小的形式，因为前面的父类必定能把后面子类能够捕获的异常都拦截，后面的子类 catch 代码块永远不会执行，成了死代码，这在 java 上是不被允许的
然而从小到大的形式是被允许的

temp.java：
public class temp {
    public static void main(String[] args) {
        try {
            throw new RuntimeException();
        }catch(RuntimeException e){
            System.out.println(e.getMessage());
        }catch(Exception e){
            System.out.println(e.getMessage());
        }
    }
}
