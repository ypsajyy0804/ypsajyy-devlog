FILE *fopen(const char *filename, const char *mode);

filename	文件路径或文件名
mode	打开模式：
	r：read，读取。
	w：write，写入（会清空原文件）。
	a：append，追加。

返回值：
- 成功：返回一个 FILE *。
- 失败：返回 NULL。


char *fgets(char *str, int n, FILE *stream);

str	用来存放读取内容的字符数组
n	最多读取多少个字符（包含结尾的 \0）
stream	从哪个文件流读取，也就是 FILE *
只从从文件中读取一行，如果在读取上限以内遇到了换行符，fgets 会把换行符也读进来，读到换行符后就停止，不会继续读取下一行。

返回值：
读取成功：返回 str，也就是你传进去的字符数组地址。
读取失败或已经到达文件末尾且没有读到字符：返回 NULL。
