任务三：
指针变量 p 保存了 int 变量 x 的内存地址，bad(p); 调用 bad 函数之后，p = NULL，传入的指针变量 p 转而变成一个“空指针”（这是 mian 函数里的指针变量 p 的一个副本，而不是  mian 函数里真正的指针变量 p），mian 函数里的指针变量 p 依旧指向 x，p 本身的值不是 NULL，所以 p ? "非 NULL" : "NULL" 表示为 "非NULL"；
接着指针变量 q 又保存了 int 变量 x 的内存地址，传入 good 函数的参数为 &q，即指针变量 q 本身值的地址（不是 x 的地址，并且这个 q 本身值的地址也是一个副本），此时 good 函数中的形参 *pp 表示为 *(&q)，直接利用 main 函数里 q 本身值的地址的副本，找到了 main 函数里真正的 q 本地的值，这不等于往 good 函数里传入保存了 int 变量 x 内存地址的指针变量 q 的副本；*pp 为 q ，*pp = NULL 就是把 main 函数里真正的 q  本身的值改为 NULL，此时 mian 函数的指针变量 q 变成空指针，所以 q ? "非 NULL" : "NULL" 应该表示为 "NULL";
综上，bad 函数改的是 main 函数里 p 指针的一个副本值，main 函数的 p 指针的值不变；

在 B06 里，insert 函数的形参：(Node* head, int pos, int val)，其中传入的 Node* head 同样也是 mian 函数里真正结构体指针 head 的一个副本值，而不是  mian 函数里的 head 值，所以 insert 函数定义返回 head 的副本值，再 main 函数里把副本值 赋值给 真正的 head；如果 insert 的返回值为 void，没有放回值，那么正在的 head 值不会改变，如果往链表的表头插入元素就会出错。
