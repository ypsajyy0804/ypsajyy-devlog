# 过去

已经发生的事。

## 这里放什么

- **项目复盘** —— 做过的项目，不管结果好坏。重点不是「我做成了」，而是「我当时怎么想的、踩了什么坑、还有什么没搞懂」
- **折腾记录** —— 装的环境、玩的工具、试过但没做成的事
- **能力快照** —— 某个时间点的自评，用来以后对比

## 这里不放什么

- 计划、目标、还没做的事 → 那是 [`future/`](../future/)
- 每周打卡、正在写的代码 → 那是 [`present/`](../present/)

## 规则

**复盘在事情告一段落时写，不是开始时。** 还在做的项目可以放个 stub，标上「进行中」，但别急着写结论——你还没资格评价一件没做完的事。

## 每篇复盘的写法

见 [`projects/_template.md`](projects/_template.md)。核心是最后一节：

> **遗留问题 —— 哪些地方我现在回头看还是不懂？**

这一节是**过去和未来之间的桥**。项目做完了但问题没解决，那些问题就是你接下来的学习清单。没有这一节，复盘就只是流水账。
