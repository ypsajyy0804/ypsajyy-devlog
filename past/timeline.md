# 大事记

> ⚠️ 日期是从对话记录回溯的，**大部分是大概时间**，不对的自己改。
> 这个文件的价值不在于精确，在于看清「哪段时间我在干什么、为什么转向」。

---

## 2024（大一）

学 Java 基础语法。**摸索式学习，没有建立起连续的体系**——这是后来所有问题的根源。

当时的学习方式：跟着课程走，但很少自己动手写完整的东西。

## 2024 – 2025（大一末 ~ 大二）

AI 编程工具兴起，开始用 Claude Code 等做项目。

- 做出 2–3 个 **Spring Boot + Maven + Vue 3** 前后端分离小项目
- 模式：提需求 → AI 生成 → 配置 → 跑起来
- 结果：项目能跑，但**三层架构的业务逻辑和接口代码读不懂**

→ 复盘见 [`projects/01-spring-boot-vue.md`](projects/01-spring-boot-vue.md)

## 2025（大二）

开始接触真实工程。

- 在 GitHub 上维护一个前后端分离项目，走了一遍 Git 分支/重构/协作流程
- 用 Docker 做容器化部署：MySQL + Spring Boot + 前端容器
- **踩了坑**：环境配置文件误提交进仓库，之后学 `.gitignore` 和安全拆分提交
- 参与一个面向小学古诗词学习的智能记忆系统设计（多端 + 多角色）

→ 复盘见 [`projects/02-acg-hub.md`](projects/02-acg-hub.md)、[`projects/03-poetry-memory.md`](projects/03-poetry-memory.md)

## 2025 – 2026（大二末 ~ 大三前）

**环境折腾期。** 这段时间写代码不多，但把一堆工具用熟了：

- Ubuntu 云服务器 / 虚拟机：SSH、SFTP、systemd、UFW、Docker Compose、自建 Git 服务
- Android 设备刷机：LineageOS、TWRP、scrcpy 无线连接
- 环境工具：VMware、Miniconda、SDKMAN
- 本地大模型：Ollama；也试过用多个智能体分工做项目的设想

→ 记录见 [`experiments.md`](experiments.md)

> 回头看：这段经历让我对「服务怎么跑起来」有直觉，但**没让我理解服务为什么这样跑**。

## 2026 上半年

出现两个**转向的信号**——两次「不用框架」的实验：

1. 用普通 Java 的 `ServerSocket` + 手写 URL 映射，试着理解 HTTP 请求是怎么被处理的
2. 不用 Spring，用纯 Java + JDBC + 手动加载 MySQL 驱动，观察 Java 究竟怎么连数据库

同时开始接触 C++ 和算法概念，并开始做一个偏离传统 Web 的项目（对话驱动的 TUI 渲染器）。

> 这两次实验背后是同一个问题，也是我现在整条路线的起点：
> **框架究竟替我做了什么？不用框架，我怎么把同样的功能实现出来？**

→ 复盘见 [`projects/05-tui-renderer.md`](projects/05-tui-renderer.md)

## 2026 暑假（7–8 月）

在一家小型软件公司实习，按负责人给出的需求交付了一套内部管理系统。

**真实的需求、真实的交付**——但代码主要由 AI 生成，请求链路我到现在也画不出来。

→ 复盘见 [`projects/04-internship.md`](projects/04-internship.md)

## 2026-09（大三上开学）

做了一次能力盘点，结论：**项目经验领先于底层理解。**

决定不再堆叠增删改查项目，转向系统方向：`C → 数据结构 → Linux → C++ → 网络编程 → Go → 云原生`。

## 2026-09-27

制定 48 周路线图。基线 20 小时/周。

## 2026-10-12

开这个仓库。

**两周后复盘发现：卡点不是「不想学」，是「不知道写什么」。** 之前把周任务写成了「数组：内存布局、越界后果」这种抽象说法，那不是能开工的指令。

→ 对策：新增练习清单目录，把抽象任务翻译成能直接动手的题目。

## 2026-10-13

仓库重构为 **过去 / 现在 / 未来** 三段。

原因：第一版里八成内容都是在为计划服务，过去只在自评里以「我缺什么」的形式出现。**把一个做过项目、踩过部署坑、自己刷过机的人写成一份缺口清单，是不准确的。**
