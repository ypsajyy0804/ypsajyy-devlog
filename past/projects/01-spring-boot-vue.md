## 踩过的坑

| 现象 | 怎么发现的 | 根因 | 解决了吗 |
|---|---|---|---|
| 端口被占用，启动失败 | 报错里写了 `Address already in use` | 上次没关干净 / 别的程序占了 | ✅ 但当时是靠搜索 |
| 前后端跨域请求被拒 | 浏览器控制台 | 同源策略，需要 CORS 配置 | ⚠️ 加了 `@CrossOrigin` 就行，**但我不知道为什么** |
| 依赖下载不下来 | Maven 报错 | 镜像源 / 网络 | ✅ 换了镜像 |
| 数据库连不上 | 启动报错 | 账号密码 / 时区 / 驱动版本 | ⚠️ 试出来的 |

## 学到了什么

- 一个 Web 项目的**形状**：前端、后端、数据库、配置文件各在哪
- 分层这个**概念**（Controller / Service / Mapper 各干什么）
- 配置怎么改、服务怎么跑起来
- Maven 依赖大概是干什么的

**没学到的**：代码到底怎么执行的。
