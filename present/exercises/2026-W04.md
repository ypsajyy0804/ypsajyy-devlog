# P 区 · 指针（C 线）

> 你已经会用 `->` 和 `*` 了，所以这五题不教「什么是指针」。
> 它们打的是 §0 里你自己承认的盲区：**指针运算**。
>
> ⚠️ P 区下面的代码是**给你跑的实验**，不是给你抄的实现。全部照抄进 `code/c/` 跑一遍，看输出。

### P01 · 指针加 1，到底加了多少？

```c
#include <stdio.h>

int main(void) {
  int a[5] = {10, 20, 30, 40, 50};
  int *p = a;

  printf("p     = %p\n", (void *)p);
  printf("p + 1 = %p\n", (void *)(p + 1));
  printf("差值  = %ld\n", (long)((char *)(p + 1) - (char *)p));
  return 0;
}
```

- **期望输出**：两行地址相差 **4**，差值那行打印 `4`
- **必须回答**：`p + 1` 为什么不是加了 1 个字节？
- **提示**：查「指针算术（pointer arithmetic）的步长由什么决定」

### P02 · `a[i]` 到底是什么

```c
#include <stdio.h>

int main(void) {
  int a[5] = {10, 20, 30, 40, 50};
  printf("%d %d %d\n", a[2], *(a + 2), 2[a]);
  return 0;
}
```

- **期望输出**：`30 30 30`
- **必须回答**：`2[a]` 为什么也能编译通过？
- **提示**：C 标准里 `a[i]` 的定义式就是 `*(a + i)`。加法满不满足交换律？

### P03 · 数组一当参数就「缩水」

```c
#include <stdio.h>

void f(int a[5]) {
  printf("函数里 sizeof(a) = %zu\n", sizeof(a));
}

int main(void) {
  int a[5];
  printf("main 里 sizeof(a) = %zu\n", sizeof(a));
  f(a);
  return 0;
}
```

- **期望输出**：`20` 和 `8`
- **必须回答**：两个 `sizeof` 为什么不一样？`int a[5]` 这个写法在参数位置到底意味着什么？
- **提示**：查「数组退化（array decay）」

### P04 · 野指针 vs 悬垂指针

两段分开跑，**每段单独一个文件**，都用 `-fsanitize=address` 编译：

```c
// P04a.c —— 野指针：从来没指向过有效内存
int main(void) {
  int *p;
  *p = 10;
  return 0;
}

// P04b.c —— 悬垂指针：指向的内存已经被还回去了
#include <stdlib.h>
int main(void) {
  int *q = malloc(sizeof(int));
  free(q);
  *q = 10;
  return 0;
}
```

- **期望输出**：两个都报 `AddressSanitizer` 错误（报错文字不一样）
- **必须回答**：这两种错误有什么不同？为什么第二种在没开 sanitizer 时可能「什么都不发生」？
- **编译命令**：`gcc -g -fsanitize=address -o build/P04a P04a.c`

### P05 · 指针的指针：`insert` 为什么要返回 `head`

```c
#include <stdio.h>

void bad(int *p)   { p = NULL; }
void good(int **pp) { *pp = NULL; }

int main(void) {
  int x = 1;
  int *p = &x;

  bad(p);
  printf("bad  之后 p 是 %s\n", p ? "非 NULL" : "NULL");

  int *q = &x;
  good(&q);
  printf("good 之后 q 是 %s\n", q ? "非 NULL" : "NULL");
  return 0;
}
```

- **期望输出**：`bad 之后 p 是非 NULL`、`good 之后 q 是 NULL`
- **必须回答**：`bad` 里改了 `p`，`main` 里为什么没变？这和 `B06` 里 `insert` 返回 `Node *`
  而不是 `void insert(Node *head, ...)` **是同一件事** —— 说出它们怎么对应。

# V 区 · 手写 `Vector`（数据结构线，本周主线）

> 只给签名，不给实现。这是你的项目，不是我的。
> 每一步写之前先想清楚「内存从哪来、什么时候还」，写完用 `valgrind` 验。

文件：`code/c/vector.c`

### V01 · 结构定义 + 生命周期（周二）

```c
typedef struct {
  int    *data;
  size_t  size;      // 已在用的元素个数
  size_t  capacity;  // 已分配能装多少个
} Vec;

void vec_init(Vec *v);   // 初始化
void vec_free(Vec *v);   // 释放
```

- **验收**：`vec_init` 之后 `size == 0`、`capacity == 0`、`data == NULL`；
  `vec_free` 之后 valgrind 报 `0 bytes in 0 blocks`（可以接受 `init` 里直接分配 4 个）
- **必须回答**：为什么 `size` 和 `capacity` 要是**两个**数，不能只用一个？

### V02 · `push_back` + 扩容（周二，本周最重要一题）

```c
void vec_push(Vec *v, int x);
```

- **验收**：连续 `vec_push` 0~15 共 16 个数，每 push 一次打印 `size` / `capacity`，
  能清楚看到 `capacity` 按 **1 → 2 → 4 → 8 → 16** 走
- **必须回答**：为什么是**翻倍**，不是每次 `+1`？
  （提示：算一下 push 16 个数，两种策略各要复制多少次元素）
- **这题有一个经典陷阱**：扩容后 `v->data` 指向新地址，**原来保存的指针全部失效**。
  写完之后自己解释一遍这是为什么。

### V03 · `reserve` 与 `resize`（周六）

```c
void vec_reserve(Vec *v, size_t n);  // 只改容量，不改 size
void vec_resize(Vec *v, size_t n);   // 改 size（变大补 0，变小截断）
```

- **验收**：`reserve(100)` 之后 `size` 不变、`capacity >= 100`；
  `resize(3)` 之后多出来的元素是 `0`
- **必须回答**：`resize` 变小时，需要 `free` 内存吗？为什么？

### V04 · `insert` / `erase`（周六）

```c
void vec_insert(Vec *v, size_t pos, int x);
void vec_erase(Vec *v, size_t pos);
```

- **验收**：`{1,2,3,4}` 上 `insert(2, 9)` → `{1,2,9,3,4}`；`erase(0)` → `{2,9,3,4}`
- **必须回答**：这两个操作最坏要移动多少元素？复杂度是多少？
- **和 B06 对照**：链表插入删除是 O(1) 但查找 O(n)，数组反过来。说清这个取舍。

### V05 · `valgrind` 全绿（周日）

```bash
gcc -g -Wall -Wextra -Werror -o build/vector vector.c
valgrind --leak-check=full --show-leak-kinds=all ./build/vector
```

- **验收**：`All heap blocks were freed -- no leaks are possible` 出现
- **必须回答**：如果 `vec_free` 忘了 `free(v->data)`，valgrind 会报哪一行、报多少 bytes？

# O 区 · 网络 / OS（周六，1 小时）

### O01 · 亲眼看进程的五种状态

```bash
# 1. 睡眠态 S
sleep 300 &
ps -o pid,stat,cmd -p $!

# 2. 停止态 T
kill -STOP <上面那个 pid>
ps -o pid,stat,cmd -p <pid>

# 3. 恢复
kill -CONT <pid>

# 4. 僵尸态 Z
python3 -c "import os,time; p=os.fork(); (os._exit(0) if p==0 else time.sleep(30))" &
sleep 1
ps -o pid,stat,cmd -C python3
```

- **验收**：亲眼看到 `S`、`T`、`Z` 三种状态的进程，把 `ps` 输出原样贴过来
- **必须回答**：`Z` 状态的进程**已经死了**，为什么它还占着一个 PID？
- **提示**：查「僵尸进程为什么存在」「`wait()` 在等什么」
