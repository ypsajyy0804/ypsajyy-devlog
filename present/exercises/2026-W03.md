## A 区：补课（W1–W2 你只看了视频，没动手，这里补上）

### A01 · 编译第一个程序
写一个程序，输出三行：一句中文、一个整数、一个浮点数。**故意**把 `printf` 的格式串写错一次（比如用 `%d` 输出字符串），看编译器报什么。
- ⚠️ 别在练习代码里写真实姓名/学号/手机号——这个仓库是公开的
- **验收**：你能逐字解释 `file:line:col: error: ...` 里每一段是什么意思
- **提示**：`man 3 printf`

### A02 · 变量与类型大小
定义 `char` / `short` / `int` / `long` / `float` / `double` / 指针 各一个变量，用 `sizeof` 打印它们的大小。
- **验收**：你能说出「为什么 `int` 是 4 字节」「指针的 `sizeof` 为什么都一样大」

### A03 · printf 格式化
用同一个整数，分别用 `%d` `%u` `%x` `%o` `%c` 输出。再用一个负数，看 `%d` 和 `%u` 的差异。
- **验收**：你能解释负数用 `%u` 输出时那个巨大的数是怎么来的

### A04 · 三个数排序
输入三个整数，用 `if` 把它们按从小到大输出。**不许用数组，不许用排序函数。**
- **验收**：`-1 5 -3`、`0 0 0`、`5 4 3` 三组输入结果都对

### A05 · 九九乘法表
用嵌套循环打印九九乘法表，要求对齐。
- **验收**：输出是三角形（不是矩形），列对齐

### A06 · 判断素数 + 打印 1~100 的素数
写一个 `is_prime(int n)`，再在主函数里打印 1–100 的素数。
- **验收**：边界（0、1、2、负数）你的函数分别返回什么？**先说清你打算怎么处理，再写代码**

### A07 · 求最大公约数
用两种方法各写一遍：辗转相除、穷举。对比哪个快。
- **验收**：你能说清辗转相除为什么是对的（不是「书上这么写」）

### A08 · 一个函数，返回两个值
写一个函数，同时算出两个整数的和与积，通过指针参数返回。
- **验收**：你能说清「为什么 `return` 只能返回一个值，而指针参数可以做到两个」

## B 区：W3 新内容（字符串与 `char*` · 权限 · 单链表）

> 这块是**指针入门**。A08 已经让你碰过一次了。慢慢来，一题卡一小时很正常。

### B01 · `char*` 与 `char[]` 的区别
定义 `char s1[] = "hello";` 和 `char *s2 = "hello";`，然后：
1. 分别打印它们的 `sizeof`
2. 分别打印它们的地址
3. 试着修改 `s1[0]` 和 `s2[0]`，各会发生什么？
- **验收**：你能解释「为什么一个能改，一个不能改」——**这题是本轮最重要的题，别跳过**
- **提示**：查「字符串字面量的存储位置」和「存储期（storage duration）」

### B02 · 手写 `strlen`
不用 `<string.h>`，自己写一个求字符串长度的函数。用 `while` 和指针两种写法各一遍。
- **验收**：空字符串 `""` 返回 0；对 B01 里两个字符串都能正确算长度

### B03 · 手写 `strcpy`
自己实现字符串复制。**先想清楚：目标缓冲区要多大？如果不够大，会发生什么？**
- **验收**：你能说清「溢出」发生后，程序为什么**可能不报错但结果是错的**

### B04 · 反转字符串（原地）
不申请新数组，把字符串原地反转。
- **验收**：奇数长度、偶数长度、空串、单字符四种情况都对

### B05 · 链表节点定义
定义 `struct Node`，写一个函数创建 3 个节点并串联起来，再遍历打印。
- **验收**：你会画图——在纸上画出内存里这几个节点的关系，标出每个指针指向哪
- **提示**：`typedef struct Node { int val; struct Node *next; } Node;`

### B06 · 单链表插入与删除
在 B05 基础上，实现「在第 i 个位置插入」和「删除第 i 个节点」。
- **验收**：**在纸上画出插入时指针的修改顺序**。想清楚：如果先改 `head` 再找位置会怎样？
- **⚠️ 这题的经典坑**：删除头节点 / 插入到头部时，你的代码还对吗？自己先测这两种情况

### B07 · 反转单链表（迭代）
把链表反转，不许用递归、不许用额外数组。
- **验收**：0 个节点、1 个节点、2 个节点、3+ 个节点都能过。**画图推指针，别硬想**

### B08 · 文件权限实验（Linux）
在 WSL / Ubuntu 里：
1. 创建一个脚本文件，`./` 运行它 → 会发生什么？
2. `chmod +x` 之后再运行
3. 用 `ls -l` 读懂输出里那 10 个字符
- **验收**：你能逐个字符解释 `-rwxr-xr--` 的意思，并说出对应的数字表示
