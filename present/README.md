## 三条自我约束

**1. 看视频 / 看书不算完成。**
只有代码写出来了、跑通了、能解释了，才算。这条是 2026-10-12 加上的——因为前两周证明了「只输入、不输出」可以持续很久而不产生任何能力。

**2. 每个 bug 都要留记录。**
现象 → 用了什么工具 → 根因 → 修复。写进当月 journal。
**这份记录比项目本身值钱**——面试时它是你唯一能拿出「我真的自己写过、自己调过」的证据。

**3. 手写的代码才放 `code/`。**
复制来的、AI 生成的，不放这里。放了就是在骗自己。
