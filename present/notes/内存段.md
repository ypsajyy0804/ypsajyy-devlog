# 字符串字面量 "hello" 在哪个段？s1 那个数组在哪个段？
根据：
~~~html
(gdb) p s2
$1 = 0x555555556004 "hello"
(gdb) p &s1
$2 = (char (*)[6]) 0x7fffffffd8c2

s1数组落在栈内（stack），"hello"落在/mnt/d/Claude_code/职业规划导师/present/code/c/build/B01 这个可执行文件对应的只读内存映射区域这个段

# 这个东西以后在哪用得上？举两个例子
看了下 roadmap.md，我只知道在排错时可以用到，其它不了解；
例子的话，就举：
char* s2 = "hello";
s2[0] = 'H';
这个段错误的例子，我用 gdb 命令p s2 查这个字符串字面量的段内存，用info proc  mappings 来对照，发现它所在的段内存区域权限“r--p”无写（w）的权限，上面的程序相当于写入了不可写入的内存，导致段错误
只能举这一个例子，其它的场景也没遇到过
