## 定向学习 · 两层指针长什么样（15 分钟）

新建 `present/code/c/levels.c`，内容**逐字**是这个：

```c
#include <stdio.h>

int main(void) {
    int x = 100;
    int *p = &x;
    int **pp = &p;

    printf("&x   = %p\n", (void *)&x);
    printf("p    = %p\n", (void *)p);
    printf("&p   = %p\n", (void *)&p);
    printf("pp   = %p\n", (void *)pp);
    printf("*p   = %d\n", *p);
    printf("**pp = %d\n", **pp);
    return 0;
}
```

> `(void *)` 是把地址「当成一个纯地址」的写法 —— `%p` 要的就是这个类型。这不是今天的考点，照抄。

编译跑：

```bash

./build/levels
```

**三问，答完抄进交付：**

1. 六行输出里，有**两对**地址是一模一样的。写出是哪两对（用行名写，例如「`&x` 和 `p`」），并说清为什么相同。
2. 从 `pp` 出发拿到 `100` 要取两次。写出**第一步**取出的是什么、**第二步**取出的是什么。
3. `sizeof(p)` 和 `sizeof(pp)` 各是多少？为什么两个数相等 —— `**` 有没有让 `pp` 变大？

## 任务 1 · 只交换指针，不动字符串（50 分钟）

**文件**：`present/code/c/M01.c`

主函数**照抄**下面这段，一个字都不许改（改了就没法判）：

```c
int main(void) {
    char *words[5] = {"banana", "a", "cherry", "fig", "elderberry"};

    printf("排序前：");
    for (int i = 0; i < 5; i++) printf(" %s", words[i]);
    printf("\n");

    sort_by_len(words, 5);

    printf("排序后：");
    for (int i = 0; i < 5; i++) printf(" %s", words[i]);
    printf("\n");

    return 0;
}
```

文件顶部需要的 `#include` 自己写全（`printf` 要 `<stdio.h>`，`strlen` 要 `<string.h>`）。
除了这些，你要自己写出**两个函数**：

```c
void swap_str(char **a, char **b);
void sort_by_len(char *arr[], int n);
```

### `swap_str` 的行为，写死如下

| 情况 | 做什么 |
|---|---|
| 任何时候 | 交换 `*a` 和 `*b` 这两个**指针值**（不是它们指向的那些字符） |
| 任何时候 | 不打印任何东西；没有返回值 |

### `sort_by_len` 的行为，写死如下

| 情况 | 做什么 |
|---|---|
| `n <= 1` | 什么都不做，直接返回 |
| 一般情况 | 按每个字符串的 `strlen` **升序**排列 `arr`。升序 = 短的在前、长的在后 |
| 两个字符串**长度相同** | **保持它们在原数组里的先后顺序**。例：`banana`（6）原本在 `cherry`（6）前面，排完还是 `banana` 在前 |
| 整个过程中 | **只允许交换 `arr` 里的指针**，不许复制、不许移动字符串内容 |
| 交换的时候 | **必须调用 `swap_str`**，不许在 `sort_by_len` 里自己写临时变量交换 |
| 整个过程中 | 不许调用 `qsort` |
| 整个过程中 | 不许出现 `malloc` / `strcpy` / `strncpy` / `strdup` / `memcpy` 这些名字 |

> 出错路径：这题**不分配任何内存**，所以没有「分配失败」要处理。`n` 只会是 5。

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/M01 M01.c` **零输出**
- `./build/M01` 的输出**逐字**是这两行：

```
排序前： banana a cherry fig elderberry
排序后： a fig banana cherry elderberry
```

> 第二行里 `banana` 在 `cherry` 前面 —— 这一处就是查你「长度相同保持原顺序」的。如果打成 `cherry banana`，排序是不稳定的。

- `grep -E 'malloc|strcpy|strncpy|strdup|memcpy' M01.c` **没有任何输出**
- `valgrind --leak-check=full ./build/M01` 结尾是 `All heap blocks were freed`

### 必须回答

1. `swap_str` 的形参为什么必须是 `char **a`？如果写成 `char *a`，函数里 `a = b;` 这一句改到的是什么、**改不到的是什么**？
2. `sort_by_len(char *arr[], int n)` 和 `sort_by_len(char **arr, int n)` 是不是一回事？`words` 传进函数之后，`arr` 里面装的是 5 个字符串，还是 5 个地址？

## 任务 2 · `const` 锁住的是哪一环（40 分钟）

### 第一步：故意违规，看编译器怎么拦（15 分钟）

```c
#include <stdio.h>

void set_first(const char *s) {
    s[0] = 'X';

char *get(const char *s) {
    return s;
}

    return 0;
}
```

```bash

```

**一问**：这两处都在「违反 `const`」，报出来的错误**是同一个名字吗**？如果不是，分别叫什么？各自指的是哪一行、锁住的是哪一环？

> 这两行都编不过，所以 `build/badconst` 不会生成。这是对的，不是环境坏了。

### 第二步：写一个返回 `const char *` 的函数（25 分钟）

**文件**：`present/code/c/M02.c`

主函数**照抄**：

```c
int main(void) {
    const char *words[5] = {"banana", "a", "cherry", "fig", "elderberry"};

    const char *p = longest(words, 5);
    printf("longest = %s\n", p);

    const char *q = longest(words, 0);
    printf("empty   = %s\n", q == NULL ? "(null)" : q);

    return 0;
}
```

你要写的函数：

```c
const char *longest(const char *arr[], int n);
```

行为**写死如下**：

| 情况 | 做什么 |
|---|---|
| `n <= 0` | 返回 `NULL` |
| 一般情况 | 返回**最长那个字符串的首地址**；不复制、不 `malloc`、不改任何东西 |
| 两个字符串长度相同 | 返回**靠前**的那一个（靠前 = 下标更小） |
| 返回值类型 | 必须是 `const char *`，不能是 `char *` |

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/M02 M02.c` **零输出**
- `./build/M02` 的输出**逐字**是这两行：

```
longest = elderberry
empty   = (null)
```

- `grep -E 'malloc|strcpy|strncpy|strdup|memcpy' M02.c` **没有任何输出**
- `valgrind --leak-check=full ./build/M02` 结尾是 `All heap blocks were freed`

### 必须回答

1. `main` 里写的是 `const char *words[5]`，任务 1 里写的是 `char *words[5]`。多出来的这个 `const` 锁住了哪一环？如果在 `main` 里写一句 `words[0][0] = 'X';`，你会拿到哪一类报错 —— 用你在 `badconst.c` 里抄下来的原话回答。
2. `longest` 的返回值写成 `char *` 行不行？用 `badconst.c` 里 `get` 那个错误来说明：谁在拦、拦的是什么。
