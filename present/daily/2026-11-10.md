## 定向学习 · 六个表达式（20 分钟）

新建 `present/code/c/bits_op.c`，照抄（这是诊断实验）。

```c
#include <stdio.h>

int main(void) {
    printf("%d %d %d\n", 5 & 3, 5 | 3, 5 ^ 3);
    printf("%d %d\n", ~5, -8 >> 1);
    printf("%u\n", 1u << 31);
    return 0;
}
```

`gcc -Wall -Wextra -o build/bits_op bits_op.c && ./build/bits_op`

应该打出三行：

```
1 7 6
-6 -4
2147483648
```

### 三问

1. `~5` 打出来是 `-6`，不是一个 42 亿多的大正数。为什么？`~` 有没有「放过」符号位？
2. `-8 >> 1` 打出来是 `-4`。如果规则是「右移就补 0」，这行该打出什么？gcc 实际做的是哪种右移？
3. `1u << 31` 是 `2147483648`。把那个 `u` 去掉、写成 `1 << 31`，你预期打出什么？这个 `u` 到底在防什么？

## 任务 1 · 把 32 位打印出来（35 分钟）

**文件**：`present/code/c/bits.c`，新建。

函数签名：

```c
void print_bits(unsigned v);
```

**行为**：把 `v` 的 32 个二进制位从左到右打印出来，**最高位在最左边，最低位在最右边**，32 个字符打完换行。

`main` 里依次调用这五个：

```c
print_bits(5);
print_bits(6);
print_bits(7);
print_bits(~5u);
print_bits(1u << 31);
```

输出必须**逐字**是这五行：

```
00000000000000000000000000000101
00000000000000000000000000000110
00000000000000000000000000000111
11111111111111111111111111111010
10000000000000000000000000000000
```

**限制**：不许查表、不许用字符串数组、不许用 `printf` 的八进制/十六进制格式绕过去。只允许循环 + 移位 + `&`。

### 必须回答

1. 你的循环跑了几次？第 `i` 次循环打印的是 `v` 的第几位？
2. 参数是 `unsigned`。如果改成 `int`、调用 `print_bits(-1)`，你预期会发生什么？为什么？

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/bits bits.c` 零输出
- 五行逐字对上
- 两问答了

## 任务 2 · 用 1 个 `unsigned` 存 8 个开关（35 分钟）

**文件**：`present/code/c/flags.c`，新建。

三个函数，签名照给：

```c
void flags_set(unsigned *flags, int idx, int on);
int  flags_get(unsigned flags, int idx);
int  flags_count(unsigned flags);
```

规格写死：

| 项 | 要求 |
|---|---|
| `idx` 范围 | `0` ~ `7`。**越界时 `flags_set` 什么都不做，`flags_get` 返回 `0`** |
| `flags_set` | `on` 非 0 → 把第 `idx` 位置 1；`on` 为 0 → 把第 `idx` 位清 0。**其余位一个都不许动** |
| `flags_get` | 第 `idx` 位是 1 返回 `1`，否则返回 `0` |
| `flags_count` | 返回第 0~7 位里 1 的个数（只看低 8 位） |

`main` 里**必须**依次执行这五行：

```c
unsigned f = 0;
flags_set(&f, 0, 1);
flags_set(&f, 3, 1);
flags_set(&f, 7, 1);
flags_set(&f, 9, 1);
flags_set(&f, 3, 0);
```

然后打印四行，**逐字**是：

```
f = 129
bit0 = 1
bit3 = 0
count = 2
```

> 一行提醒：`&f` 里的 `&` 是**取地址**，函数体里的 `&` 是**按位与**。同一个符号两个意思，看上下文。

### 必须回答

1. `f` 在五次 `flags_set` 之后分别是多少？写出每一步的**十进制和十六进制**。
2. `flags_count` 里你是怎么数 1 的？如果循环固定跑 8 次，想想能不能让它**只跑「1 的个数」那么多次**。

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/flags flags.c` 零输出
- 四行逐字对上
- 两问答了
