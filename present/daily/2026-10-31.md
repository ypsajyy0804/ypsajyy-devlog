## 任务 1 · 手写一个栈（55 分钟）

**文件**：`present/code/ds/S01.c`（新建。目录还没有就先 `mkdir -p present/code/ds`）

**结构体和常量固定这样**：

```c
#define STACK_CAP 8

typedef struct {
    int data[STACK_CAP];
    int top;            /* 指向下一个可用的位置 */
} Stack;
```

**必须实现下面四个函数，就四个，名字和签名一字都不能改**：

```c
void stack_init(Stack *s);                 /* 把栈清空 */
int  stack_push(Stack *s, int v);          /* 满了返回 0；成功返回 1 */
int  stack_pop(Stack *s, int *out);        /* 空返回 0（不许碰 *out）；成功写 *out 返回 1 */
int  stack_is_empty(const Stack *s);       /* 空返回 1，否则返回 0 */
```

**除此之外**：辅助函数你自己加，加几个、叫什么随你。判断标准只有一条 —— 上面这四个函数必须存在、签名一字不差。

**`main` 里必须按这个顺序做**：

1. `stack_init`，打印 `printf("init: is_empty=%d\n", stack_is_empty(&s));`
2. 依次 push `3`、`7`、`11`，每 push 一次打印一行 `push %d -> %d`
3. `stack_pop` 一次拿到 `out`，打印 `printf("pop -> %d, is_empty=%d\n", out, stack_is_empty(&s));`
4. 现在栈里还有 2 个元素。**再 push 6 个把栈填满**（值随便，这几步不打印）。满了之后再 push 一次 `99`，打印 `printf("push 满 -> %d\n", stack_push(&s, 99));`
5. **pop 到空**（8 次，不打印）。空了之后再 pop 一次，打印 `printf("pop 空 -> %d\n", stack_pop(&s, &out));`

**逐字输出**（七行）：

```
init: is_empty=1
push 3 -> 1
push 7 -> 1
push 11 -> 1
pop -> 11, is_empty=0
push 满 -> 0
pop 空 -> 0
```

**验收标准**：

- `gcc -g -Wall -Wextra -Werror -o ./build/S01 S01.c` 零警告
- `./build/S01` 输出逐字是上面七行
- `valgrind --leak-check=full ./build/S01` → 0 errors、0 leaks（这个程序不用 `malloc`）
- 空栈时 `stack_pop` **不许写 `*out`**

**必须回答**：`stack_push` 用 `int` 返回 0 / 1，而不是像 `vec_reserve` 那样返回 `void` ——
这样写解决了你 10-25 那版 `vec_resize` 的什么问题？一句话。
