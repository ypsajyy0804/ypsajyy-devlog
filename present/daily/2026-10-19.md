## 定向学习 · 指针 `+1` 走多远，由谁决定（20 分钟）

一句话：**指针自己固定 8 字节，但 `p + 1` 往前走多远，由 `p` 指向的类型决定。**

先猜，再跑。把下面这段跑起来，看三个数：

```c
#include <stdio.h>
int main(void) {
  int    a[2];
  char   b[2];
  double c[2];
  printf("%ld %ld %ld\n",
         (long)((char *)(a + 1) - (char *)a),
         (long)((char *)(b + 1) - (char *)b),
         (long)((char *)(c + 1) - (char *)c));
  return 0;
}
```

**验收**：先写下你猜的三个数，再跑。跑完能说出：
「`int *` +1 走 4 字节、`char *` +1 走 1 字节、`double *` +1 走 8 字节」，
以及**为什么不是全部走 1 字节**。

> 先猜再跑的规矩是有用的：猜错的地方才是你真正没懂的地方。

## 任务 1 · P01 指针加 1，到底加了多少（30 分钟）

```c
#include <stdio.h>

int main(void) {
  int a[5] = {10, 20, 30, 40, 50};
  int *p = a;

  printf("p     = %p\n", (void *)p);
  printf("p + 1 = %p\n", (void *)(p + 1));
  printf("差值  = %ld\n", (long)((char *)(p + 1) - (char *)p));
  return 0;
}
```

- **期望输出**：两行地址相差 **4**，差值那行打印 `4`
- **必须回答**：`p + 1` 为什么不是加了 1 个字节？

> 存成 `code/c/P01.c`，用 `gcc -Wall -Wextra -Werror` 编。

## 任务 2 · P02 `2[a]` 为什么也能编译（30 分钟）

```c
#include <stdio.h>

int main(void) {
  int a[5] = {10, 20, 30, 40, 50};
  printf("%d %d %d\n", a[2], *(a + 2), 2[a]);
  return 0;
}
```

- **期望输出**：`30 30 30`
- **必须回答**：`2[a]` 为什么也合法？
- **提示**：C 标准里 `a[i]` 的定义式就是 `*(a + i)`。那么加法满不满足交换律？
