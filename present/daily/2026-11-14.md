## 定向学习 · 一个 12 字节的文件（20 分钟）

新建 `present/code/c/bin_io.c`，照抄（诊断实验）。

```c
#include <stdio.h>

int main(void) {
    int a[3] = {1, 2, 3};

    FILE *fp = fopen("num.bin", "wb");
    size_t n = fwrite(a, sizeof(int), 3, fp);
    printf("wrote = %zu\n", n);
    fclose(fp);

    fp = fopen("num.bin", "rb");
    fseek(fp, 0, SEEK_END);
    long size = ftell(fp);
    printf("size = %ld\n", size);
    fclose(fp);
    return 0;
}
```

`gcc -Wall -Wextra -o build/bin_io bin_io.c && ./build/bin_io && xxd num.bin`

应该打出：

```
wrote = 3
size = 12
```

后面跟着 `xxd` 的十六进制。

### 三问

1. `fwrite` 返回 **3**，不是 12。它数的是什么单位？如果把参数改成 `fwrite(a, 1, 12, fp)`，返回值会是多少？
2. `xxd` 里那 12 个字节，`1`、`2`、`3` 各占哪几个字节？为什么第一个字节不是 `01`？
3. 假设磁盘满了，`fwrite` 只写进去 1 个元素。**你上面这段代码知道吗？** 它接下来会照常打印什么？

## 任务 1 · 二进制记录文件（45 分钟）

**文件**：`present/code/c/recdb.c`，新建。

结构体，照给：

```c
struct Rec {
    int    id;
    char   name[16];
    double score;
};
```

**用法**：`./build/recdb <文件名> <子命令> [参数...]`

| 子命令 | 行为 |
|---|---|
| `write` | 如果文件不存在，写入下面 3 条记录；**如果文件已存在，什么都不做**，打印 `exists, skip` |
| `show` | 读出全部记录并打印 |
| `patch <id> <分数>` | 用 `fseek` **原地**找到 `id` 等于给定值的那条记录，只改它的 `score`，其余字节不动 |

三条记录固定是：

| id | name | score |
|---|---|---|
| 1 | alice | 90.50 |
| 2 | bob | 85.00 |
| 3 | carol | 77.25 |

### 期望输出（四条命令，逐字）

```
$ ./build/recdb rec.bin write
wrote 3 records, 96 bytes

$ ./build/recdb rec.bin show
id=1 name=alice score=90.50
id=2 name=bob score=85.00
id=3 name=carol score=77.25

$ ./build/recdb rec.bin patch 2 99.00
patched id=2

$ ./build/recdb rec.bin show
id=1 name=alice score=90.50
id=2 name=bob score=99.00
id=3 name=carol score=77.25
```

### 顺带给你的 API（纯记忆，直接用）

| 东西 | 说明 |
|---|---|
| `int main(int argc, char **argv)` | `argc` 是参数个数（含程序名）；`argv[0]` 是程序名，`argv[1]` 是第一个参数 |
| `atoi(const char *s)` | 字符串转 `int`，要 `#include <stdlib.h>` |
| `atof(const char *s)` | 字符串转 `double`，同上 |
| `fseek(fp, 偏移, SEEK_SET)` | 从**文件开头**数偏移。另外两个起点是 `SEEK_CUR`、`SEEK_END` |

### 必须回答

1. 一条记录是 32 字节，3 条是 96。**逐字节**说这 32 个字节里，哪些是 `id`、哪些是 `name`、哪些是 `score`、哪些是空着的。
2. `patch` 时你怎么算出「第 2 条记录」在文件里的偏移？`id` 和「第几条」是同一件事吗？如果记录不是按 id 排序的呢？

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/recdb recdb.c` 零输出
- 四条命令的输出逐字对上（含 `write` 第二次跑时的 `exists, skip`）
- 两问答了
