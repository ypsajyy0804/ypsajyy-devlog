## 定向学习 · AddressSanitizer 的报错怎么读（20 分钟）

先造一个必然越界的程序：

```c
#include <stdio.h>
int main(void) {
  int a[3] = {1, 2, 3};
  a[3] = 99;          // 越界：合法下标只有 0..2
  printf("%d\n", a[3]);
  return 0;
}
```

编译并运行：

```bash
gcc -g -fsanitize=address -o build/asan_demo asan_demo.c
./build/asan_demo
```

对着报错，逐段找到这三样东西：

1. `ERROR: AddressSanitizer: ...` 后面那一行说的是什么错误类型
2. `WRITE of size 4` 里的 `4` 是什么意思
3. 报错里 `#0 ... in main file.c:5` 那行的**行号**指向哪一行

**验收**：能指出「越界写发生在第几行」「写了几个字节」。不用看懂整份报错。

## 任务 1 · P03 数组一当参数就「缩水」（30 分钟）

```c
#include <stdio.h>

void f(int a[5]) {
  printf("函数里 sizeof(a) = %zu\n", sizeof(a));
}

int main(void) {
  int a[5];
  printf("main 里 sizeof(a) = %zu\n", sizeof(a));
  f(a);
  return 0;
}
```

- **期望输出**：`20` 和 `8`
- **必须回答**：两个 `sizeof` 为什么不一样？`int a[5]` 写在参数位置，到底意味着什么？
- **提示**：查「数组退化（array decay）」

## 任务 2 · P04 野指针 vs 悬垂指针（30 分钟）

**两个文件分开写**，都用 `-fsanitize=address` 编译：

```c
// P04a.c —— 野指针：从来没指向过有效内存
int main(void) {
  int *p;
  *p = 10;
  return 0;
}
```

```c
// P04b.c —— 悬垂指针：指向的内存已经被还回去了
#include <stdlib.h>
int main(void) {
  int *q = malloc(sizeof(int));
  free(q);
  *q = 10;
  return 0;
}
```

- **验收**：两个都报 `AddressSanitizer` 错误，把两段报错的**第一行**都贴过来
- **必须回答**：这两种错误有什么不同？为什么 `P04b` 在**不开** sanitizer 时可能「什么都不发生」？
- **提示**：`free` 到底做了什么？它把内存还给了谁？还回去之后，那 4 个字节变了吗？

## 任务 3 · P05 指针的指针（30 分钟）

```c
#include <stdio.h>

void bad(int *p)    { p = NULL; }
void good(int **pp) { *pp = NULL; }

int main(void) {
  int x = 1;
  int *p = &x;
  bad(p);
  printf("bad  之后 p 是 %s\n", p ? "非 NULL" : "NULL");

  int *q = &x;
  good(&q);
  printf("good 之后 q 是 %s\n", q ? "非 NULL" : "NULL");
  return 0;
}
```

- **期望输出**：`bad 之后 p 是非 NULL`、`good 之后 q 是 NULL`
- **必须回答**：`bad` 里明明改了 `p`，`main` 里为什么没变？
  这和 `B06` 里 `insert` 返回 `Node *`、而不是写成 `void insert(Node *head, ...)` **是同一件事** ——
  说出它们怎么对应。
