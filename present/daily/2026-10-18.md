## 定向学习 · `ls -l` 第一列那 10 个字符（20 分钟）

随便找一个文件，敲 `ls -l`。只看**第一列**：

```
-rwxr-xr--  1 ypsajyy ypsajyy  123 Oct 18 10:00 hello.sh
│└─┬─┘└─┬─┘└─┬─┘
│  │    │    └── 其他人（other）
│  │    └─────── 同组（group）
│  └──────────── 属主（user）
└─────────────── 文件类型：- 普通文件   d 目录   l 符号链接
```

每组三位，分别是 **`r` 读（read）/ `w` 写（write）/ `x` 执行（execute）**，没有这个权限就是 `-`。

**数字写法**：`r=4`、`w=2`、`x=1`，三位相加就是这一组的值。

| 权限 | 三位 | 数字 |
|---|---|---|
| `rwx` | 4+2+1 | 7 |
| `rw-` | 4+2+0 | 6 |
| `r-x` | 4+0+1 | 5 |
| `r--` | 4+0+0 | 4 |
| `---` | 0+0+0 | 0 |

例：`-rwxr-xr--` → 7 5 4 → `chmod 754`

**验收**：合上这份文档，能说出 `-rw-r--r--` 和 `-rwx------` 的数字写法。

## 任务 1 · B06 单链表 `insert` / `erase`（50 分钟，昨天顺延）

**说死**：**单**链表，只要 `next`，**不要** `prev`。

```c
typedef struct Node { int val; struct Node *next; } Node;

// 在第 pos 个位置插入（pos 从 0 开始；pos == 当前长度 表示插到末尾）
// 返回新的 head
Node *insert(Node *head, int pos, int val);

// 删除第 pos 个节点，返回新的 head
Node *erase(Node *head, int pos);
```

**pos 的语义（写死，不要自己理解）**

- `insert(head, pos, val)`：新节点插进去之后，**成为从头数第 `pos` 个**（下标从 0 数）。
  即：原来第 `pos` 个节点，变成第 `pos+1` 个。
- `erase(head, pos)`：**删掉从头数第 `pos` 个**（下标从 0 数）。
- `pos == 0` 一律是「动 head 本身」的那种情况。

**必须测这 7 组**（每组都重新建一条链表，不要在上一条的残留上接着做）：

| # | 初始链表 | 完整调用 | 跑完之后打印 | 期望输出 |
|---|---|---|---|---|
| 1 | `head = NULL` | `head = insert(head, 0, 9)` | `print_list(head)` | `9` |
| 2 | `1→2→3` | `head = insert(head, 0, 9)` | `print_list(head)` | `9 1 2 3` |
| 3 | `1→2→3` | `head = insert(head, 2, 9)` | `print_list(head)` | `1 2 9 3` |
| 4 | `1→2→3` | `head = insert(head, 3, 9)` | `print_list(head)` | `1 2 3 9` |
| 5 | `1→2→3→4` | `head = erase(head, 0)` | `print_list(head)` | `2 3 4` |
| 6 | `1→2→3→4` | `head = erase(head, 3)` | `print_list(head)` | `1 2 3` |
| 7 | `1` | `head = erase(head, 0)` | `head == NULL ? "NULL" : "非NULL"` | `NULL` |

`print_list` 是这个格式，照抄进你的 `main` 上方（它不是本题的答案，是尺子）：

```c
void print_list(Node *p) {
  for (; p; p = p->next) printf("%d ", p->val);
  printf("\n");
}
```

> 注意 `print_list` 是**一直走到 `NULL` 才停**。第 4、6 组专门治「末节点的 `next` 忘了置 `NULL`」——
> 那种情况下它要么多打一个数，要么直接段错误。**这就是这两组的意义，不是凑数。**

**验收**：7 组输出与上表逐字一致 + 在纸上画出 `insert(head, 0, 9)`（第 2 组）时指针的**修改顺序**。

**这题唯一的难点**：插入/删除头部会改变 `head` **本身**。返回 `Node *` 就是为这个。
先想清楚：如果签名写成 `void insert(Node *head, ...)`，头部怎么做？

> 昨天 `p1->prev = NULL` 那件事，这题的版本是：**新建的节点，`next` 必须在 `insert` 里就赋好值**
> —— 否则就是同一个洞，只不过这次变量名换成了 `next`。
