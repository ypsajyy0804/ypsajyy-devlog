## 定向学习 · `ls -l` 第一列那 10 个字符（20 分钟）

随便找一个文件，敲 `ls -l`。只看**第一列**：

```
-rwxr-xr--  1 ypsajyy ypsajyy  123 Oct 18 10:00 hello.sh
│└─┬─┘└─┬─┘└─┬─┘
│  │    │    └── 其他人（other）
│  │    └─────── 同组（group）
│  └──────────── 属主（user）
└─────────────── 文件类型：- 普通文件   d 目录   l 符号链接
```

每组三位，分别是 **`r` 读（read）/ `w` 写（write）/ `x` 执行（execute）**，没有这个权限就是 `-`。

**数字写法**：`r=4`、`w=2`、`x=1`，三位相加就是这一组的值。

| 权限 | 三位 | 数字 |
|---|---|---|
| `rwx` | 4+2+1 | 7 |
| `rw-` | 4+2+0 | 6 |
| `r-x` | 4+0+1 | 5 |
| `r--` | 4+0+0 | 4 |
| `---` | 0+0+0 | 0 |

例：`-rwxr-xr--` → 7 5 4 → `chmod 754`

**验收**：合上这份文档，能说出 `-rw-r--r--` 和 `-rwx------` 的数字写法。

## 任务 1 · B06 单链表 `insert` / `erase`（50 分钟，昨天顺延）

**说死**：**单**链表，只要 `next`，**不要** `prev`。

```c
typedef struct Node { int val; struct Node *next; } Node;

// 在第 pos 个位置插入（pos 从 0 开始；pos == 当前长度 表示插到末尾）
// 返回新的 head
Node *insert(Node *head, int pos, int val);

// 删除第 pos 个节点，返回新的 head
Node *erase(Node *head, int pos);
```

**必须测这 7 组**（自己在 `main` 里构造并调用，不许心算）：

| # | 操作 | 期望 |
|---|---|---|
| 1 | 空链表 `insert(0)` | 变成 1 个节点，返回的 head 不为 NULL |
| 2 | 3 个节点，`insert(0)` | 头部换人，新节点 `next` 指向原 head |
| 3 | 3 个节点，`insert(2)` | 中间接上，长度变 4 |
| 4 | 3 个节点，`insert(3)`（= 长度） | 接在末尾 |
| 5 | 4 个节点，`erase(0)` | head 变了 |
| 6 | 4 个节点，`erase(3)` | 前一个的 `next == NULL` |
| 7 | 1 个节点，`erase(0)` | 返回 `NULL` |

**验收**：7 组全过 + 在纸上画出「`insert(0)`」时指针的**修改顺序**。

**这题唯一的难点**：插入/删除头部会改变 `head` **本身**。返回 `Node *` 就是为这个。
先想清楚：如果签名写成 `void insert(Node *head, ...)`，头部怎么做？

> 昨天 `p1->prev = NULL` 那件事，这题的版本是：**新建的节点，`next` 必须在 `insert` 里就赋好值**
> —— 否则就是同一个洞，只不过这次变量名换成了 `next`。
