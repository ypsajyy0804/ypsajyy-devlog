## 定向学习 · 三个数字（20 分钟）

新建 `present/code/c/macro_op.c`，照抄（诊断实验）。

```c
#include <stdio.h>

#define SQR(x)  x * x
#define MAX(a, b)  ((a) > (b) ? (a) : (b))

int main(void) {
    printf("%d\n", SQR(1 + 2));
    printf("%d\n", MAX(1, 2));
    printf("%d\n", 100 / SQR(2));
    return 0;
}
```

`gcc -Wall -Wextra -o build/macro_op macro_op.c && ./build/macro_op`

应该打出三行：

```
5
2
100
```

### 三问

1. `SQR(1 + 2)` 打出 **5**，不是 9。把这一行**手动展开**写成一行，看看 `+` 和 `*` 谁先算。
2. `MAX(1, 2)` 打出 2，是对的。`#define` 里那**两层括号**，各自在防什么？如果去掉里面那层，`MAX(a+1, b)` 会出什么事？
3. `100 / SQR(2)` 打出 **100**，不是 25。把这一行展开，看除号的作用范围到哪儿为止。

## 任务 1 · 一个能一键关掉的日志宏（35 分钟）

**文件**：`present/code/c/log_macro.c`，新建。

**规格**：定义宏 `LOG(msg)`，用法 `LOG("start");`

| 编译方式 | `LOG` 展开成什么 |
|---|---|
| 带 `-DDEBUG` | 打印一行：`[` + 文件名 + `:` + 行号 + `] ` + 消息 |
| 不带 `-DDEBUG` | **什么都不做，一个字节都不打印** |

`main` 里**必须**依次有三个 `LOG` 调用，消息依次是 `start`、`big`、`done`（中间可以夹别的语句，随便）。

两条编译命令：

```bash
gcc -Wall -Wextra -Werror -DDEBUG -o build/log_dbg log_macro.c
gcc -Wall -Wextra -Werror          -o build/log_rel log_macro.c
```

**期望输出**（`__FILE__` 取决于你怎么调 gcc，从 `present/code/c/` 里编，它就叫 `log_macro.c`）：

- `./build/log_dbg` —— **三行**，格式逐字是 `[log_macro.c:行号] 消息`，行号是那个 `LOG` 调用在文件里的真实行号
- `./build/log_rel` —— **零行**（不是空行，是一个字符都没有；用 `./build/log_rel | wc -c` 验证，必须是 `0`）

### 必须回答

1. `-DDEBUG` 到底做了什么事？它和你在文件第一行写 `#define DEBUG 1` 有什么区别？
2. 关掉 DEBUG 之后跑 `gcc -E log_macro.c`，找到 `LOG("start")` 那一行展开成了什么？贴出来。

### 验收（三条）

- 两条 `gcc` 命令都零输出
- `./build/log_dbg` 三行、格式对上；`./build/log_rel | wc -c` 输出 `0`
- 两问答了

## 任务 2 · 一个能报行号的检查宏（35 分钟）

**文件**：`present/code/c/check.c`，新建。

**规格**：定义宏 `CHECK(cond)`，用法 `CHECK(表达式);`

| 情况 | 行为 |
|---|---|
| 表达式为真 | 打印一行 `ok` |
| 表达式为假 | 打印一行 `FAIL at <行号>`（行号是**那个 `CHECK` 调用所在的行**），然后**退出程序，退出码 1** |

`main` 里**必须**依次是这四行：

```c
CHECK(1 + 1 == 2);
printf("after first\n");
CHECK(2 > 3);
printf("never\n");
```

**期望输出**逐字是：

```
ok
after first
FAIL at 5
```

（`5` 是第二条 `CHECK` 在你文件里的真实行号，不是固定 5。）

要求：`echo $?` 必须是 `1`，并且 `never` 这一行**不能出现**。

### 必须回答

1. `__LINE__` 是在哪一步被替换成数字的？你在 `gcc -E` 的输出里能直接看到数字吗？
2. 如果把这句写成 `if (1) CHECK(1 + 1 == 2); else printf("else\n");` —— 你现在的宏会不会出问题？**先猜，再改代码验证**，把结果告诉我。

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/check check.c` 零输出
- 三行逐字对上，`echo $?` 是 `1`，`never` 没出现
- 两问答了
