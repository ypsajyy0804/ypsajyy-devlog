## 定向学习 · 亲眼看见 padding（20 分钟）

新建 `present/code/c/pad.c`，把下面这段**照抄**进去（这是诊断实验，不是你的作业代码）。

```c
#include <stdio.h>

struct A { char c; int  i; char d; };
struct B { int  i; char c; char d; };
struct C { char c; char d; int  i; };
struct D { char c; long l; char d; };
struct E { char c; char pad[3]; int i; char d; };

int main(void) {
    printf("A=%zu B=%zu C=%zu D=%zu E=%zu\n",
           sizeof(struct A), sizeof(struct B), sizeof(struct C),
           sizeof(struct D), sizeof(struct E));
    return 0;
}
```

**先别编译。** 拿张纸把 A–E 五个数猜出来，写在纸上。然后 `gcc -o build/pad pad.c && ./build/pad`，对答案。

### 三问（口头答，不用写长篇）

1. A 和 B 字段一模一样，只是顺序不同。**你猜的数差了几字节？实际差了几字节？** 差的那几字节原来放的是什么？
2. D 比「1 + 8 + 1 = 10」大了很多。它是多少，为什么是这个数？
3. E 和 A 唯一的区别是多写了一个 `char pad[3]`。**E 的大小和 A 一样吗？** 这件事说明了什么？

## 任务 1 · 把每个字段的偏移算出来（40 分钟）

**文件**：`present/code/c/layout.c`，新建。

结构体定义，照给：

```c
struct Emp {
    char   name[12];
    int    age;
    double salary;
    char   grade;
};
```

`main` 里定义一个 `struct Emp e;`，然后打印两样东西：它的大小，以及**每个字段的地址减去结构体起始地址**（单位：字节）。

输出必须**逐字**是这六行：

```
sizeof = 32
name   = 0
age    = 12
salary = 16
grade  = 24
```

> 提示（只此一条）：如果编译器报「指针类型不兼容」，那不是编译器找茬 —— C 在告诉你，**两个指针相减的单位，由它们指向的类型决定**。你自己想想该把什么转成什么。

### 必须回答

1. 四个字段加起来是 `12 + 4 + 8 + 1 = 25` 字节，为什么 `sizeof` 是 32？多出来的 7 个字节分别在哪两处？
2. `salary` 的偏移为什么是 16 而不是 13？

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/layout layout.c` 零输出
- `./build/layout` 六行逐字对上
- 两问答了，且第 1 问要说出**两处** padding 各几字节

## 任务 2 · 把一个 24 字节的结构体压到 16（30 分钟）

**文件**：`present/code/c/pack.c`，新建。

下面这个结构体，字段和顺序都**不许改**，叫 `struct M_before`：

```c
struct M_before {
    char   a;
    double b;
    int    c;
    char   d;
};
```

你要在同一份文件里再定义一个 `struct M_after`，**字段一个不少、类型一个不许改**，只允许改变它们在结构体里的**排列顺序**，使它的大小变成 16。

输出必须**逐字**是这两行：

```
before = 24
after  = 16
```

### 必须回答

1. `struct M_after` 的 16 个字节，从偏移 0 数到 15，**逐字节**说这是什么（哪个字段、还是 padding）。
2. `struct M_before` 里，`c` 的偏移是多少？为什么不是 9？

### 验收（三条）

- `gcc -Wall -Wextra -Werror -o build/pack pack.c` 零输出
- `./build/pack` 两行逐字对上
- 两问答了，第 1 问要写到字节级
