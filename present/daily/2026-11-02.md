## 任务 1 · 括号匹配（45 分钟）

**文件**：`present/code/ds/S03.c`（新建，就这一个）

### 这个函数要判什么

给你一个以 `'\0'` 结尾的字符串，判断里面的括号**是不是成对、且嵌套顺序正确**。
字符串里除了括号还可能有别的字符，那些一律当没看见。

### 字符怎么分类

只认下面 6 个字符，其余（字母、数字、空格、`+` `*` 等）全部属于「其他字符」。

- **左括号**：`(` `[` `{`
- **右括号**：`)` `]` `}`

**配对关系只有这三对**：`(` 配 `)`、`[` 配 `]`、`{` 配 `}`。左边三个不能互配，比如 `(]` 就是不配。

### 从左到右一个字符一个字符地扫，读到每个字符时只做一件事

| 读到的是 | 做什么 |
|---|---|
| 左括号 | 把它**压进栈**，然后看下一个字符 |
| 右括号，**此时栈是空的** | **立即返回 `0`** |
| 右括号，栈不空，**栈顶和它不是一对** | **立即返回 `0`** |
| 右括号，栈不空，**栈顶和它是一对** | **把栈顶弹出去**，然后看下一个字符 |
| 其他字符 | 什么都不做，看下一个字符 |

### 扫到字符串结尾 `'\0'` 之后

- 栈是**空**的 → 返回 **`1`**
- 栈**不空**（还剩没配对的左括号）→ 返回 **`0`**

### 函数签名

```c
int bracket_match(const char *s);   /* 完全匹配返回 1，否则返回 0 */
```

栈自己实现 —— **可以直接抄你 `S01.c` 里的那四个函数**，也可以重写。辅助函数随你加，加几个都行。

### `main` 里必须这样调用，一行一句

```c
printf("%s -> %d\n", "()",       bracket_match("()"));
printf("%s -> %d\n", "([{}])",   bracket_match("([{}])"));
printf("%s -> %d\n", "(]",       bracket_match("(]"));
printf("%s -> %d\n", "(()",      bracket_match("(()"));
printf("%s -> %d\n", ")(",       bracket_match(")("));
printf("%s -> %d\n", "a(b)c[d]", bracket_match("a(b)c[d]"));
```

### 逐字输出（六行）

```
() -> 1
([{}]) -> 1
(] -> 0
(() -> 0
)( -> 0
a(b)c[d] -> 1
```

### 验收标准

- `gcc -g -Wall -Wextra -Werror -o ./build/S03 S03.c` 零警告
- `./build/S03` 输出逐字是上面六行
- `valgrind --leak-check=full ./build/S03` → 0 errors

### 必须回答

`")("` 和 `"(()"` 都返回 `0`，但它们是上面表格里**两条不同的规则**判出来的 ——
分别说出：这两个输入各触发了哪一条规则？
