## 任务 1 · 把链表挂到数组上（50 分钟）

**文件**：`present/code/c/ht.c`，新建。

### 结构体，照给

```c
typedef struct Node {
    char        *key;
    int          val;
    struct Node *next;
} Node;

typedef struct {
    Node    **buckets;
    unsigned  bucket_count;
    unsigned  size;
} HT;
```

### 五个函数，签名照给

```c
HT      *ht_create(unsigned bucket_count);
void     ht_free(HT *h);
int      ht_put(HT *h, const char *key, int val);
int      ht_get(const HT *h, const char *key, int *out);
unsigned ht_count(const HT *h);
```

规格写死：

| 函数 | 要求 |
|---|---|
| `ht_create` | `bucket_count == 0` → 返回 `NULL`。分配 `buckets` 数组并清零（`calloc` 最省事）。失败返回 `NULL` |
| `ht_put` | key **已经存在** → 只改 `val`，返回 `0`；key **不存在** → 新建节点，返回 `1`；内存失败返回 `-1`。**key 必须复制一份存进去**（`strdup`），不能只存指针 |
| `ht_get` | 找到 → `*out` 写入值，返回 `1`；**找不到 → 不动 `*out`，返回 `0`** |
| `ht_count` | 返回已存的键值对个数 |
| `ht_free` | 今天先留空函数体，任务 2 再写 |

> 哈希函数你自己定，只要**同一个 key 每次算出同一个桶**就行。最简单的：把每个字符的 ASCII 加起来，再 `% bucket_count`。
> `strdup` 要做 `#include <string.h>`，它 `malloc` 一份字符串副本给你。

### `main` —— 你来写，必须做完这四步

1. `ht_create(8)`
2. 依次插入这 10 个：`{"one",1}` `{"two",2}` `{"three",3}` `{"four",4}` `{"five",5}` `{"six",6}` `{"seven",7}` `{"eight",8}` `{"nine",9}` `{"ten",10}`
3. 逐个 `ht_get` 读回这 10 个，值全对就打印 `10/10 ok`（**一个不对就打 `N/10 ok`**，别写死）
4. 再 `ht_get("eleven")` → 打印 `eleven: not found`
5. 再 `ht_put("three", 99)` → 打印 `put three again = <返回值>`
6. 再 `ht_get("three")` → 打印 `three = <值>, count = <ht_count>`

### 期望输出（逐字，四行）

```

eleven: not found
put three again = 0
three = 99, count = 10
```

> `strcmp` 用来比 key，允许。
