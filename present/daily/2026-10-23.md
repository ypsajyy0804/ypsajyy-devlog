## 定向学习 · 不用 Maven，命令行怎么跑一个 `.java`（15 分钟）

在任意目录建 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("hi");
    }
}
```

```bash
javac Hello.java     # 编译，产出 Hello.class
java Hello           # 运行，注意：不带 .class 后缀
```

**验收**：说出 `javac` 和 `java` 各自干了什么；说出为什么 `java Hello` 不能写成 `java Hello.class`。

> 试一次 `java Hello.class`，把报错抄下来 —— 那个报错就是在告诉你它要的是**类名**不是**文件名**。

## 任务 1 · 写代码：`finally` 的四种走法（40 分钟）

> 从今天起，**每份施工单的第一道任务都是写代码**（你 10-22 提的：跑实验不算锻炼）。

**先预测，再跑。** 不许写完直接运行 —— 预测错的地方才是没懂的地方。

自己写 `Order.java`，四个方法：

```java
static int a() { try { return 1; } finally { System.out.print("[a]"); } }
static int b() { try { return 1; } finally { return 2; } }
static int c() { try { throw new RuntimeException("x"); } finally { System.out.print("[c]"); } }
static int d() { try { return 1; } finally { throw new RuntimeException("y"); } }
```

`main` 里依次调用，每个用 `try { ... } catch (...) { ... }` 包住，打印返回值或捕获到的异常。

**先写下四个结果，再编译运行。**

- **必须回答一**：`b()` 为什么返回 `2`，不是 `1`？
- **必须回答二**：`c()` 抛异常的时候，`[c]` 打印了吗？`finally` 是在异常传播的**哪一步**执行的？
- **必须回答三**：`d()` 最后抛出来的是哪个异常？`try` 里的 `return 1` 去哪了？

## 任务 3 · J03 环境搭建（30 分钟，**今天只搭环境，不写业务代码**）

> 环境配置属于 `CLAUDE.md` §6 例外 —— 直接给，不用你自己摸索。

建一个干净的 Maven 项目 `book-demo`，`pom.xml` 最少要这几样：

```xml
<parent>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-parent</artifactId>
  <version>3.2.0</version>
</parent>

<dependencies>
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
  </dependency>
  <dependency>
    <groupId>org.mybatis.spring.boot</groupId>
    <artifactId>mybatis-spring-boot-starter</artifactId>
    <version>3.0.3</version>
  </dependency>
  <dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
  </dependency>
</dependencies>
```

`application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bookdb?useSSL=false&serverTimezone=UTC
    username: root
    password: 你的密码
mybatis:
  mapper-locations: classpath:mapper/*.xml
```

建表 SQL：

```sql
CREATE DATABASE IF NOT EXISTS bookdb DEFAULT CHARSET utf8mb4;
USE bookdb;
CREATE TABLE book (
  id     BIGINT PRIMARY KEY AUTO_INCREMENT,
  title  VARCHAR(64) NOT NULL,
  author VARCHAR(64) NOT NULL
);
```

- **验收**：`mvn spring-boot:run` 能起来，控制台出现 `Tomcat started on port 8080`，
  然后把这一行原样贴过来
- **必须回答**：`localhost:3306` 这个 MySQL 你装在哪了？WSL 里还是 Windows 里？
  （这决定后面 JDBC 的地址要不要改）
