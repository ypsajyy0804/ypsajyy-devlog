## 定向学习 · 把函数装进一个变量（15 分钟）

新建 `present/code/c/fptr.c`，内容**逐字**是这个：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

int main(void) {
    int (*f)(int, int);

    f = add;
    printf("f(2,3) = %d\n", f(2, 3));

    f = mul;
    printf("f(2,3) = %d\n", f(2, 3));

    printf("sizeof(f) = %zu\n", sizeof(f));
    return 0;
}
```

编译跑：

```bash
gcc -Wall -Wextra -Werror -o build/fptr fptr.c
./build/fptr
```

应该打出三行：`f(2,3) = 5`、`f(2,3) = 6`、`sizeof(f) = 8`。

**三问，答完抄进交付：**

1. `f = add;` 这一句，赋进 `f` 里去的是什么？（不是 `add` 算出来的结果 —— 那时候 `add` 还没被调用）
2. 同一个 `printf`、同一个 `f(2, 3)`，为什么第一次打 `5`、第二次打 `6`？
3. `int (*f)(int, int);` 里那对括号要是去掉，写成 `int *f(int, int);`，`f` 变成了什么？

## 任务 1 · 写一个「对每个元素做同一件事」的函数（40 分钟）

**文件**：`present/code/c/FP01.c`

下面这段**照抄**，一个字都不许改（`print_arr` 和 `main` 是脚手架，不是今天的题目）：

```c
void print_arr(const char *label, const int *a, int n) {
    printf("%s:", label);
    for (int i = 0; i < n; i++) printf(" %d", a[i]);
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};

    map(a, 5, dbl);
    print_arr("dbl", a, 5);

    map(a, 5, neg);
    print_arr("neg", a, 5);

    map(a, 5, sq);
    print_arr("sq", a, 5);

    map(a, 0, dbl);
    print_arr("n=0", a, 5);

    map(a, -3, dbl);
    print_arr("n=-3", a, 5);

    return 0;
}
```

文件顶部需要的 `#include` 自己写全。

你要写的是**四个函数**：

```c
int  dbl(int x);
int  neg(int x);
int  sq(int x);
void map(int *arr, int n, int (*op)(int));
```

`dbl` / `neg` / `sq` 各自是什么，写死如下：

| 函数 | 返回什么 | 例 |
|---|---|---|
| `dbl` | `x * 2` | `dbl(3)` → `6` |
| `neg` | `-x` | `neg(3)` → `-3` |
| `sq` | `x * x` | `sq(3)` → `9` |

`map` 的行为，写死如下：

| 情况 | 做什么 |
|---|---|
| `n <= 0` | 什么都不做，直接返回 |
| 一般情况 | 对 `i = 0 … n-1`，把 `arr[i]` **替换成** `op(arr[i])` 的返回值（就在原数组上改，不新建数组） |
| 任何时候 | 不打印任何东西；不 `malloc`；无返回值 |

> 出错路径：这题**不分配任何内存**，所以没有「分配失败」要处理。

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/FP01 FP01.c` **零输出**
- `./build/FP01` 的输出**逐字**是这五行：

```
dbl: 2 4 6 8 10
neg: -2 -4 -6 -8 -10
sq: 4 16 36 64 100
n=0: 4 16 36 64 100
n=-3: 4 16 36 64 100
```

- `grep -E 'malloc|calloc|realloc' FP01.c` **没有任何输出**
- `valgrind --leak-check=full ./build/FP01` 结尾是 `All heap blocks were freed`

### 必须回答

1. `main` 里写的是 `map(a, 5, dbl)`。为什么传的是 `dbl`，而不是 `dbl(3)`、也不是 `dbl()`？
2. `map` 的函数体里，`op` 是怎么被调用起来的？它和调用 `dbl(a[i])` 有什么不一样 —— 写 `map` 的时候，你知道 `op` 最终会是哪个函数吗？

## 任务 2 · 排序规则由参数决定（50 分钟）

**文件**：`present/code/c/FP02.c`

下面这段**照抄**：

```c
void print_arr(const char *label, const int *a, int n) {
    printf("%s:", label);
    for (int i = 0; i < n; i++) printf(" %d", a[i]);
    printf("\n");
}

int main(void) {
    int a[6] = {5, -3, 8, 1, -9, 0};
    sort(a, 6, asc);
    print_arr("asc", a, 6);

    int b[6] = {5, -3, 8, 1, -9, 0};
    sort(b, 6, desc);
    print_arr("desc", b, 6);

    int c[6] = {5, -3, 8, 1, -9, 0};
    sort(c, 6, by_abs);
    print_arr("abs", c, 6);

    return 0;
}
```

你要写的是**四个函数**：

```c
int  asc(int a, int b);
int  desc(int a, int b);
int  by_abs(int a, int b);
void sort(int *arr, int n, int (*cmp)(int, int));
```

`sort` 的行为，写死如下：

| 情况 | 做什么 |
|---|---|
| `n <= 1` | 什么都不做，直接返回 |
| 一般情况 | **冒泡排序**，在 `arr` 上原地排；每次比较相邻两个元素，**当 `cmp(arr[j], arr[j + 1]) > 0` 时交换它们** |
| 长度 / 大小相同的元素 | 不许交换（判断必须写严格大于 `> 0`，不能写 `>= 0`） |
| 任何时候 | 不打印任何东西；不 `malloc`；不调用 `qsort` |

三个比较函数**返回什么**（这一个字都不能含糊）：

| 函数 | 返回 | 效果 |
|---|---|---|
| `asc` | `a - b` | 升序 |
| `desc` | `b - a` | 降序 |
| `by_abs` | `abs(a)` 和 `abs(b)` 比较的结果，**按绝对值从小到大** | 按绝对值升序 |

> `by_abs` 别偷懒写成 `a - b` —— 那样就是 `asc` 了。也不许自己写 `abs`，`<stdlib.h>` 里有现成的。

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/FP02 FP02.c` **零输出**
- `./build/FP02` 的输出**逐字**是这三行：

```
asc: -9 -3 0 1 5 8
desc: 8 5 1 0 -3 -9
abs: 0 1 -3 5 8 -9
```

- `grep -E 'malloc|calloc|realloc|qsort' FP02.c` **没有任何输出**
- `valgrind --leak-check=full ./build/FP02` 结尾是 `All heap blocks were freed`

### 必须回答

1. `sort` 的函数体里，一次都没出现「升序」「降序」「绝对值」这些词。那它是怎么排出三种顺序的？
2. `desc` 如果照着 `asc` 抄完忘了改符号，`./build/FP02` 的第二行会打成什么？（不许改代码去试，用你写的 `sort` 推一遍）
