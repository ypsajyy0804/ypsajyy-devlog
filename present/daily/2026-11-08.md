## 定向学习 · 看见「链接属性」（20 分钟）

新建两个文件，内容**逐字**照抄。

`present/code/c/sa.c`：

```c
#include <stdio.h>

int counter = 0;

static void bump(void) { counter++; }

void tick(void) { bump(); }
void report(void) { printf("counter = %d\n", counter); }
```

`present/code/c/sb.c`：

```c
#include <stdio.h>

void tick(void);
void report(void);
extern int counter;

int main(void) {
    tick();
    tick();
    tick();
    report();
    printf("from main: %d\n", counter);
    return 0;
}
```

编译跑：

```bash
gcc -Wall -Wextra -Werror -o build/st sa.c sb.c
./build/st
```

应该打出两行：`counter = 3`、`from main: 3`。

### 实验 A（只动一个词）

把 `sa.c` 第 3 行 `int counter = 0;` 改成 `static int counter = 0;`，重新跑同一条 `gcc` 命令。

**预期：编译失败，贴完整报错。**

### 实验 B（先把 A 改回去）

`sa.c` 恢复原样。把 `sb.c` 第 5 行 `extern int counter;` 改成 `int counter;`（去掉 `extern`），重新编译。

**预期：又是另一种失败，贴完整报错。**

### 三问

1. 实验 A 的报错出在哪一步 —— 预处理 / 编译 / 汇编 / 链接？从报错里哪一个词看出来的？
2. `int counter;` 和 `extern int counter;` 只差一个词，为什么一个是**定义**、一个是**声明**？两者差在哪件事上？
3. `gcc -c sa.c -o sa.o`，然后 `nm sa.o | grep -E 'bump|counter'`。
   `nm` 每行格式是「地址 类型字母 名字」；**字母小写 = 只在本文件内可见，大写 = 全局可见**。
   那么：`bump` 那行是小写还是大写？`counter` 那行呢？用一句话把它和「别的 `.o` 能不能看见」连起来。

## 任务 1 · 把实现细节藏在 `.c` 里（40 分钟）

**目录**：`present/code/c/stat/`，**三个文件**。

### `counter.h` —— 照抄，不许改

```c
#ifndef COUNTER_H
#define COUNTER_H

void counter_inc(void);
int  counter_get(void);

#endif
```

### `main.c` —— 照抄，不许改

```c
#include <stdio.h>
#include "counter.h"

int main(void) {
    counter_inc();
    printf("inc1 = %d\n", counter_get());
    counter_inc();
    printf("inc2 = %d\n", counter_get());
    counter_inc();
    printf("inc3 = %d\n", counter_get());
    printf("get = %d\n", counter_get());

    for (int i = 0; i < 1005; i++) counter_inc();
    printf("cap = %d\n", counter_get());

    return 0;
}
```

### `counter.c` —— 你来写

写死的规格如下：

| 项 | 要求 |
|---|---|
| 计数器变量 | 名字必须是 `count`，`int`，初值 `0`，**用 `static` 让它在本文件外部不可见** |
| 辅助函数 | 名字必须是 `clamp`，签名 `int clamp(int v)`；`v > 1000` 返回 `1000`，否则返回 `v`；**用 `static` 让它只在本文件内可见** |
| `counter_inc` | 函数体是 `count = clamp(count + 1);`，无返回值 |
| `counter_get` | 返回 `count` |
| 任何时候 | 不打印任何东西；不 `malloc`；不定义 `counter.h` 里没声明的函数 |

> `clamp` 不是摆设：`count` 到 1000 就停住，靠它。

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/counter main.c counter.c` **零输出**
- `./build/counter` 的输出**逐字**是这五行：

```
inc1 = 1
inc2 = 2
inc3 = 3
get = 3
cap = 1000
```

- **故意实验**：在 `main.c` 顶部加一行 `extern int count;`，再在 `main` 的第一行加一句 `count = 100;`。
  重跑同一条 `gcc` 命令 —— **必须编译通过、链接失败**，报 `undefined reference to 'count'`。
  把这条报错**完整贴出来**，然后**把这两行删掉**，恢复原样。
- `valgrind --leak-check=full ./build/counter` 结尾是 `All heap blocks were freed`

### 必须回答

1. `count = 100;` 那一行为什么是**链接**报错，不是**编译**报错？（注意 `main.c` 里已经写了 `extern int count;`）
2. `gcc -Wall -Wextra -Werror -c counter.c -o counter.o`，然后 `nm counter.o`。
   `count` 和 `clamp` 那两行，字母是小写还是大写？和 `counter_inc` 那行比，差在哪？

## 任务 2 · `static` 的另一个意思（35 分钟）

**文件**：`present/code/c/static_local.c`

注意：**这个 `static` 和任务 1 的不是同一件事。** 那个管「谁看得见」，这个管「活多久」。

> ⚠️ **2026-11-08 判：这一题第 2 条要求无解。** 「计数器定义在 `next_id` 里面」+「`peek_id` 拿到它的值」，
> 在 C 里做不到 —— 函数内的名字外面看不见，也没有嵌套函数。他做完 `next_id` 后验证并指出了这一点，
> **是他对的，题面作废，不要重做。** 下面保留原文，不删。

`main` 照抄：

```c
#include <stdio.h>

int next_id(void);
int peek_id(void);

int main(void) {
    printf("id1 = %d\n", next_id());
    printf("id2 = %d\n", next_id());
    printf("id3 = %d\n", next_id());
    printf("peek = %d\n", peek_id());
    return 0;
}
```

你要写两个函数：

```c
int next_id(void);
int peek_id(void);
```

规格写死：

| 项 | 要求 |
|---|---|
| `next_id` | 每调用一次返回 1、2、3……递增；第一次调用返回 `1` |
| `peek_id` | 返回当前值，**不递增** |
| 变量位置 | 计数器变量必须定义在 **`next_id` 函数体内部**，用 `static` 定义，初值 `0` |
| 禁止 | 不许在函数外面定义**任何**变量；不许用 `malloc`；不许打印 |
| 访问方式 | `peek_id` 里怎么拿到 `next_id` 里那个 `static` 变量，你自己想 —— 但**不许**改成全局变量 |

### 验收标准

- `gcc -Wall -Wextra -Werror -o build/sl static_local.c` **零输出**
- `./build/sl` 的输出**逐字**是这四行：

```
id1 = 1
id2 = 2
id3 = 3
peek = 3
```

- `grep -nE '^[a-z].*[a-z_]+ *=' static_local.c` 在文件最外层**搜不到任何变量定义**（变量只能出现在函数体里）
- `valgrind --leak-check=full ./build/sl` 结尾是 `All heap blocks were freed`

### 必须回答

1. 假如 `count` 那行去掉 `static`、只写 `int id = 0;`，这四行会打成什么？（**不许改代码试**，推一遍）
2. 那个 `static` 变量在进程内存里落在哪个段？为什么**不是** stack？
