## 任务 1 · 手写三个字符串函数（50 分钟）

**文件**：`present/code/c/S02.c`（新建，就这一个）

**不许 `#include <string.h>`，不许调用 `strlen` / `strcmp` / `strcpy`。** 三个函数自己写。

**必须实现下面这三个，就三个，名字和签名一个字都不能改**：

```c
size_t my_strlen(const char *s);                    /* 不数 '\0' */
int    my_strcmp(const char *a, const char *b);     /* 返回第一个不同字符的差（'h'-'w' = -15）；完全相同返回 0 */
void   my_strcpy(char *dst, const char *src);       /* 连结尾的 '\0' 一起拷 */
```

**除此之外**：辅助函数你自己加，加几个、叫什么随你。判断标准只有一条 —— 上面这三个必须存在、签名一字不差。

**`main` 里必须这样调用，一行一句**：

```c
printf("len(hello) = %zu\n",         my_strlen("hello"));
printf("len(empty) = %zu\n",         my_strlen(""));
printf("cmp(hello, hello) = %d\n",   my_strcmp("hello", "hello"));
printf("cmp(hello, world) = %d\n",   my_strcmp("hello", "world"));
printf("cmp(world, hello) = %d\n",   my_strcmp("world", "hello"));
char buf[32];
my_strcpy(buf, "hello");
printf("copy = %s\n", buf);
```

**逐字输出**（六行）：

```

len(empty) = 0
cmp(hello, hello) = 0
cmp(hello, world) = -15
cmp(world, hello) = 15
copy = hello
```
