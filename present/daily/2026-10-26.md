## 定向学习 · 两个注解怎么把方法变成一个 URL（15 分钟）

文件：`projacts/book-demo/src/main/java/com/environment/test/HelloController.java`（新建，就这一个）

```java
package com.environment.test;

import org.springframework.web.bind.annotation.*;

@RestController
public class HelloController {
    @GetMapping("/hi")
    public String hi() { return "hello"; }
}
```

重启 `mvn spring-boot:run`，**另开一个终端**：

```
curl localhost:8080/hi
```

**验收**：输出 `hello`。

## 任务 1 · 写 `BookController`，四个端点（50 分钟）

**文件只有这两个**，都在 `projacts/book-demo/src/main/java/com/environment/test/` 下：

### 1.1 `Book.java`

```java
public class Book {
    private Long id;
    private String title;
    private String author;
    /* 构造器 + 三个 getter */
}
```

> **getter 必须写全。** 少一个，返回的 JSON 里就会少一个字段 —— 今天你会亲眼看到。

### 1.2 `BookController.java`

一个 `static List<Book> books` 存数据，一个 `static long nextId = 1` 发号。
标 `@RestController`，四个端点**必须用下面这张表里写死的方法和 URL**：

| # | 方法 | URL | 做什么 |
|---|---|---|---|
| 1 | `POST` | `/book?title=X&author=Y` | 新建一本，返回新 id |
| 2 | `GET` | `/book` | 列出全部 |
| 3 | `GET` | `/book/{id}` | 按 id 查一本 |
| 4 | `DELETE` | `/book/{id}` | 删一本，返回 `true` / `false` |

`{id}` 用 `@PathVariable` 接，`title` / `author` 用 `@RequestParam` 接。

### 1.3 四条 curl，输出必须逐字对上

```bash
curl -s -X POST "localhost:8080/book?title=CProgramming&author=KR"
```

**期望输出**：`1`

```bash
curl -s localhost:8080/book
```

**期望输出**：`[{"id":1,"title":"CProgramming","author":"KR"}]`

```bash
curl -s localhost:8080/book/1
```

**期望输出**：`{"id":1,"title":"CProgramming","author":"KR"}`

```bash
curl -s -X DELETE localhost:8080/book/1
```

**期望输出**：`true`

- **验收**：四条输出逐字对上
- **必须回答**：第 2 条的响应外面为什么有一对方括号 `[ ]`，第 3 条没有？
