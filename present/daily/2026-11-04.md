## 任务 2 · 用 Makefile 编同一个程序（40 分钟）

**新建 `present/code/c/Makefile`**（文件名就叫 `Makefile`，没有后缀）。

下面这份**直接照抄**（这是工具链语法，不是你今天的练习内容，所以直接给）：

```make
CC      = gcc
CFLAGS  = -Wall -Wextra -Werror
OBJ     = build/vec.o build/main.o
TARGET  = build/vec

$(TARGET): $(OBJ)
	$(CC) $(CFLAGS) $(OBJ) -o $(TARGET)

build/%.o: %.c vec.h
	$(CC) $(CFLAGS) -c $< -o $@

clean:
	rm -f build/vec.o build/main.o build/vec

.PHONY: clean
```

> ⚠️ **`$(CC)`、`$(CFLAGS)` 那几行开头是 TAB，不是空格。** 复制粘贴到编辑器后确认一下，
> 这是 Makefile 最出名的坑 —— 用空格会报 `missing separator`。
> 在 vim 里按 `:set list` 能看见 TAB 显示成 `^I`。

### 要做的三件事

**① `make clean` 然后 `make`，把完整输出贴上来。**

**② 只改一个 `.c`，看 make 编了几个文件**：

```bash
touch main.c
make
```

把输出贴上来。**数一下：这次带 `-c` 的那条命令出现了几次？**

**③ 改一个头文件，再看一次**：

```bash
touch vec.h
make
```

把输出贴上来。**这次带 `-c` 的那条命令出现了几次？和 ② 差在哪？**

### 验收标准

- `make` 之后 `./build/vec` 的输出，和 `after.txt` 仍然 `diff` 没有输出
- ②③ 两步的输出都贴了，两次「带 `-c` 的命令出现几次」都数对了
- `make clean` 之后 `ls build/` 里**没有** `vec.o` / `main.o` / `vec`

**必须回答**：

1. `build/%.o: %.c vec.h` 这一行，冒号右边的 `vec.h` 是干什么用的？
   如果把 `vec.h` 从这一行删掉，你刚做的 ③ 那一步会发生什么？
2. 为什么 `clean` 那个目标要写成 `.PHONY: clean`？不写会怎样？
