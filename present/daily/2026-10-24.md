## 定向学习 · `realloc` 到底做了什么（20 分钟）

```bash
man 3 realloc
```

只读三段：`DESCRIPTION` 第一段、`RETURN VALUE`、`NOTES` 里关于 `realloc(p, 0)` 的那句。

核心一句话：**`realloc` 可能把数据搬到新地址，也可能原地不动 —— 你无法预先知道是哪一种。**

**验收**：回答「`realloc` 返回 `NULL` 的时候，原来那块内存还在不在？」
（这题答错的人很多，去手册里找依据，别猜。）

> 顺带一个坑：`p = realloc(p, n);` 这种写法在返回 `NULL` 时会**丢掉原指针**，内存就泄漏了。
> 先想清楚正确的写法长什么样，再动手。

## 任务 1 · V03 `reserve` 与 `resize`（40 分钟）

```c
void vec_reserve(Vec *v, size_t n);  // 只改容量，不改 size
void vec_resize(Vec *v, size_t n);   // 改 size：变大补 0，变小截断
```

- **验收**：
  - `reserve(100)` 之后 `size` **不变**、`capacity >= 100`
  - `resize(3)` 之后，多出来的元素**必须是 `0`**（不能是 `malloc` 留下的垃圾）
- **必须回答**：`resize` 把 size 变小时，需要 `free` 内存吗？为什么？
- **必须回答**：`resize` 把 size 变大时，新补的那些 0 是谁写的？（这跟你昨天刚踩的 `head->next` 是同一件事）

## 任务 3 · O01 亲眼看进程的五种状态（30 分钟）

```bash
# 1. 睡眠态 S
sleep 300 &
ps -o pid,stat,cmd -p $!

# 2. 停止态 T
kill -STOP <上面那个 pid>
ps -o pid,stat,cmd -p <pid>

# 3. 恢复
kill -CONT <pid>

# 4. 僵尸态 Z
python3 -c "import os,time; p=os.fork(); (os._exit(0) if p==0 else time.sleep(30))" &
sleep 1
ps -o pid,stat,cmd -C python3
```

- **验收**：亲眼看到 `S`、`T`、`Z` 三种状态的进程，把三次 `ps` 的输出原样贴过来
- **必须回答**：`Z` 状态的进程**已经死了**，为什么它还占着一个 PID？
