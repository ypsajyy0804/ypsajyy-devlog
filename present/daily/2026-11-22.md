## 定向学习 · 桶号会跑（20 分钟）

新建 `present/code/c/resize_calc.c`，照抄。

```c
#include <stdio.h>

static unsigned hash(const char *key, unsigned n) {
    int sum = 0;
    for (const char *p = key; *p != '\0'; p++) sum += *p;
    return sum % n;
}

int main(void) {
    const char *keys[10] = {"one","two","three","four","five",
                            "six","seven","eight","nine","ten"};
    for (int i = 0; i < 10; i++)
        printf("%s: %u -> %u\n", keys[i], hash(keys[i], 8), hash(keys[i], 32));
    return 0;
}
```

`gcc -Wall -Wextra -o build/resize_calc resize_calc.c && ./build/resize_calc`

## 任务 1 · 给 `ht.c` 加 `ht_resize`（50 分钟）

**文件**：`present/code/c/ht.c`（在昨天那份上改）。

新增一个函数，签名照给：

```c
int ht_resize(HT *h, unsigned new_count);
```

规格写死：

| 项 | 要求 |
|---|---|
| `h == NULL` | 返回 `0`，什么都不做 |
| `new_count == 0` | 返回 `0`，什么都不做 |
| `new_count <= h->bucket_count` | 返回 `0`，什么都不做（**只许变大，不许变小**） |
| 成功 | 返回 `1` |
| 新数组 | `calloc(new_count, sizeof(Node*))`，**失败返回 `0`，旧表一个字节都不许动** |
| 搬节点 | **不许 `malloc`、不许 `strdup`、不许 `free` 任何 `Node` 和 `key`** —— 那些内存本来就在，只是换个位置挂 |
| 旧数组 | 搬完 `free` 掉，`h->buckets` 指向新数组 |
| `bucket_count` | 改成 `new_count` |
| `size` | **不变**（一个键值对都没增没减） |
| 新链顺序 | 不要求保持原来的顺序，插到新桶头部也可以 |

### `main` 里插六行
