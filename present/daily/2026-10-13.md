## 2 · A02 · 类型到底占多少字节

**40 分钟 ｜ 文件：`A02.c`**

用 `sizeof` 打印下面每一个的大小，**每个单独 printf 一行，并且标清楚是什么类型**：

| 类别 | 类型 |
|---|---|
| 整型 | `char` `short` `int` `long` `long long` |
| 浮点 | `float` `double` |
| 其他 | `size_t` |
| 指针 | `int*` `char*` `double*` `void*` |
| 结构体 | 自己定义 `struct { char a; int b; }` 再打印它 |

### 做完要在心里能回答

1. 你这台机器上 `int` 是几字节？`long` 和 `long long` 一样大吗？
2. 为什么 `int*`、`char*`、`double*`、`void*` 的 `sizeof` **全都一样**？它们指向的东西大小差那么远，凭什么一样？
3. `struct { char a; int b; }` 打印出来是几？如果答案是 5，那说明你对；如果不是 5，那么——为什么会多出来？

> 第 3 问是**内存对齐（memory alignment）**的入口。这一问允许你现在答不出来，
> 但必须把实际数字抄进今天的记录里。第三题禁止背答案 —— 必须是这台机器上真跑出来的数字。

### 做完要在心里能回答

2. `-1` 用 `%u` 打出来是一个很大的正整数。**为什么是这个数？**

> 第 2、3 问是你第一次撞上**补码（two's complement）**和**默认实参提升（default argument promotion）**。
