## 定向学习 · `malloc` 给你的内存是「脏」的（20 分钟）

**先读**：`man 3 malloc`，在 NOTES 段里搜 `initialized`。找到那句否定句。

**再跑**（自己写一遍，别抄）：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *p = malloc(sizeof(int) * 4);
    for (int i = 0; i < 4; i++) printf("%d ", p[i]);
    printf("\n");
    free(p);

    int *q = malloc(sizeof(int) * 4);
    for (int i = 0; i < 4; i++) printf("%d ", q[i]);
    printf("\n");
    return 0;
}
```

两次输出一样吗？再把第一次的 `malloc` 换成 `calloc(4, sizeof(int))`，跑第三遍。

**验收**：合上这份文档能说出 —— `malloc` **保证**什么、**不保证**什么。

## 任务 2 · B06 单链表插入与删除（50 分钟）

**这次说死**：**单**链表，只要 `next`，**不要** `prev`。

```c
typedef struct Node { int val; struct Node *next; } Node;

// 在第 pos 个位置插入（pos 从 0 开始；pos == 当前长度 表示插到末尾）
// 返回新的 head
Node *insert(Node *head, int pos, int val);

// 删除第 pos 个节点，返回新的 head
Node *erase(Node *head, int pos);
```

**必须测这 7 组**（自己在 `main` 里构造链表并调用，不许心算）：

| # | 操作 | 期望 |
|---|---|---|
| 1 | 空链表 `insert(0)` | 变成 1 个节点，返回的 head 不为 NULL |
| 2 | 已有的 3 个节点，`insert(0)` | 头部换人，新节点 `next` 指向原 head |
| 3 | 已有的 3 个节点，`insert(2)` | 中间接上，长度变 4 |
| 4 | 已有的 3 个节点，`insert(3)`（= 长度） | 接在末尾 |
| 5 | 4 个节点，`erase(0)` | head 变了 |
| 6 | 4 个节点，`erase(3)` | 前一个的 `next == NULL` |
| 7 | 只有 1 个节点，`erase(0)` | 返回 `NULL` |

**验收**：7 组全过 + 在纸上画出「`insert(0)`」时指针的**修改顺序**（先动哪根箭头）。

**提示 —— 这题唯一的难点**：插入/删除头部会改变 `head` **本身**。
函数返回 `Node *` 就是为这个。先想清楚：如果签名写成 `void insert(Node *head, ...)`，头部怎么办？
