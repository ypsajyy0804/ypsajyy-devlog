## 定向学习 · HTTP 报文长什么样（20 分钟）

不看视频、不看书，用 `curl` 看真实字节。**全程离线，不需要你的项目跑起来：**

```
cd /tmp && python3 -m http.server 8000 &
curl -v http://localhost:8000/
curl -v http://localhost:8000/nothing-here
kill %1
```

限时 20 分钟。验收（合上这份文档能说出来）：

- `curl -v` 输出里 **`>` 开头的行**是什么？**`<` 开头的行**是什么？
- 请求的第一行、响应的第一行，各长什么样？
- 两次请求的状态码为什么不一样（`200` / `404`）？

## 任务 3 · B05 链表（45 分钟）

这是**数据结构线**，但用 C 写 —— 两线并成一条。

```
typedef struct Node { int val; struct Node *next; } Node;
```

用 `malloc` 造 3 个节点、串起来、遍历打印。

- **验收**：`gcc -Wall -Wextra -Werror` 编过 + 打印出 `1 2 3` + **在纸上画出这 3 个节点和箭头，标出每个箭头指向哪**
- 画完用 gdb 对答案：`p head`、`p head->next`、`p head->next->next` ——
  你画的图必须和内存里一致。这是昨天 `p` 命令的直接复用
- 别提前想「插入/删除」，今天就只要「造出来 + 走一遍」
