## 定向学习 · `size_t` 到底是哪种类型（15 分钟）

一句话：`size_t` 是**无符号整数**，专门用来表示「大小 / 个数 / 下标」。`sizeof` 返回的就是它。

跑这两行：

```c
printf("%zu\n", sizeof(size_t));
printf("%zu\n", sizeof(int));
```

然后让它自己招供：

```bash
gcc -dM -E - < /dev/null | grep SIZE_TYPE
```

**验收**：说出「LP64 上 `size_t` 等价于哪个类型」，以及「为什么打印它要用 `%zu` 而不是 `%d`」。

## 任务 1 · V01 `Vec` 的结构与生命周期（30 分钟）

在 `code/c/vector.c` 里定义：

```c
typedef struct {
  int    *data;
  size_t  size;      // 已在用的元素个数
  size_t  capacity;  // 已分配能装多少个
} Vec;

void vec_init(Vec *v);   // 初始化
void vec_free(Vec *v);   // 释放
```

`main` 里调用一次 `vec_init` → 打印三个字段 → `vec_free`。

- **验收**：`init` 之后 `size == 0`、`capacity == 0`、`data == NULL`
  （或者你选择在 `init` 里直接分配 4 个，那 `capacity == 4`，能自圆其说就行）；
  `vec_free` 之后 valgrind 报 **`0 bytes in 0 blocks`**
- **必须回答**：为什么 `size` 和 `capacity` 要是**两个**数，不能只用一个？

> `valgrind --leak-check=full --show-leak-kinds=all ./build/vector`

## 任务 2 · V02 `push_back` + 扩容（60 分钟，本周最重要一题）

```c
void vec_push(Vec *v, int x);
```

要求：容量不够时**按 ×2 扩容**，扩完把旧数据搬过去、释放旧内存。

`main` 里连续 push 0~15 共 16 个数，**每 push 一次打印 `size` 和 `capacity`**。

- **验收**：`capacity` 的变化序列能看出 **1 → 2 → 4 → 8 → 16**
- **必须回答一**：为什么是**翻倍**，不是每次 `+1`？
  （算一下：push 16 个数，两种策略下总共要复制多少次元素）
- **必须回答二**：扩容之后 `v->data` 指向新地址，**以前保存过的旧指针还能用吗**？为什么？

> 这题有一个经典陷阱，自己先踩一次再想。踩不到也没关系，
> 但你得说出「扩容前后 `data` 的值变了没有」。
